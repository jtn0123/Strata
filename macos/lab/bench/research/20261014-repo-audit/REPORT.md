## Small experiments completed

1. **Apple advice feasibility:** two independent 8 MiB owned files per API, 1 MiB hint window, 64 pages ×16 KiB initially nonresident. Both MADV_WILLNEED and F_RDADVISE return 0 and load 64/64 pages by the first poll; controls stay 0/64 after 200 ms. Checksums all match, peak process RSS 2.906 MiB, no observed new swap, private files removed. Hint cost was212/234 µs for MADV and 59/67 µs for F_RDADVISE. Moving demand earlier does not by itself prove useful overlap or model speed; these are not SSD-throughput or cold-model measurements.
2. **Routed-map geometry:** CPU source proof at 15.6 MiB RSS, no GPU. At 512 tokens, scratch upper bound 1,050,624→30,584 bytes and tile bound 8,192→671; at 1536, 3,147,776→75,384 bytes and 24,576→991. These are tiny route scratch/launch bounds relative to model memory, not actual active tile counts, measured GPU time or 92–96% speed gains. V1 classifier mistake remains excluded before corrected proof.
3. **Failure contracts:** actual loopback mock handler, classic-script DOM installation, native packet and malformed-receipt fixtures, real tiny SIGTERM fixture and isolated file-lock probe. Owned listeners and children were reaped. Native state checkpoint exposure is source/active-log confirmed but is a watchlist requiring targeted model proof, not an observed bad answer.

## First two performance trials

**N01 integrated routing:** fix grade D8 first if reusing the shared synthetic checker; first N00 normal dispatch/fusion/shape inventory, then isolated map/tiling-only clone. Keep Q2 weights, activation precision, arithmetic/reduction order, model/helper/depth, decode path and memory policy. GPU reference tests cover T32..1536, tails, skew, duplicate IDs, strides and fallback; compare whole dependent blocks rather than a single cheap map kernel. Only then trace-off English 512/1536 first/replay A/B/B/A and independent confirmation. Stop on changed output, inactive path, total-block overhead or required-scope regression.

**N02 Apple advice:** separate clone/flag, bounded verified eligible lazy-table spans, alignment/overflow/page-byte caps, readonly file/mapping lifetime and advice errors/cancellation. Observe requested vs read bytes, residency/page-ins and actual useful overlap. Test first exposure and warm replay without purge or preload; do not combine with N01 or the loader rewrite. Stop on no overlap, warm penalty or page pressure.

Later full-model runs retain one owned model, 34 GiB admission/1 GiB running floor, normal pressure, zero new swap, frozen engine/model/harness/runner, complete normal EOS and token/counter/quality checks, tracing off for scoring and independent confirmation. Small repeatable 1% or subpercent gains remain eligible when above own drift; no addition of isolated percentages.
